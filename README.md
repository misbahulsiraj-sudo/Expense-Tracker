# 💰 Expense Tracker

A simple and user-friendly Expense Tracker built with Python to help manage daily income and expenses through a command-line interface.

## ✨ Features

- ➕ Add income
- ➖ Add expenses
- 💰 View current balance
- 📊 Track income and expenses
- 📜 View transaction details
- ❌ Input validation
- 🔄 Simple menu-driven interface

## 🛠️ Technologies Used

- Python 3
- Variables
- Lists
- Functions
- Loops
- Conditional Statements
- Exception Handling

## ▶️ How to Run

Make sure Python 3 is installed, then run:

```bash
python expense_tracker.py
